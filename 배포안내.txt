오산점 스마트 근무관리 - Vercel 배포용

이 ZIP은 기존 v64 근무관리 화면을 포함한 PWA 정적 사이트입니다.

중요: Vercel은 ZIP을 프로젝트로 바로 배포하지 못할 수 있습니다. 가장 쉬운 방법은 GitHub 저장소에 압축 해제한 파일 6개(index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, vercel.json)를 루트에 올리고 Vercel에서 Import Git Repository를 선택하는 것입니다.

Vercel 설정:
Framework Preset: Other
Root Directory: ./
Build Command: 없음
Output Directory: 비워둠(기본값)

배포 후 https://프로젝트.vercel.app/ 주소를 Chrome에서 열고 메뉴 > 홈 화면에 추가 > 설치를 확인하세요.

주의: 현재는 브라우저별 로컬 저장 방식이며 직원 간 실시간 공유 DB나 안전한 로그인은 구현되지 않았습니다. 실제 직원 개인정보/근태 운영용으로 공개 배포하기 전에 인증 및 데이터 접근 통제가 필요합니다.
